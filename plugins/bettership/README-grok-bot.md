# Bettership for Grok Bot

Use the methods you've made in Bettership in a Grok Bot conversation. The plugin connects your published skills, prompts, context packs, and Library. Each new use reads the current published version.



## Install and connect

Production distribution has not been released. Do not install the development marketplace for a production account. Use the supplied package only when your destination supports its installation, and connect to Bettership's production service.

Ask Grok Bot to use **Bettership**. Follow its connection action, sign in to Bettership, and review the requested access. Bettership Plus or Max is required for fresh hosted reads. Installing the package or seeing its card does not establish that the account is connected or the cloud computer can load the skill.

Start a new conversation and ask: **“Show me the items I've published in Bettership.”** Ask Grok Bot to use an item by name. Its own conversation must read the installed shared skill and call Bettership to load the item and its required files. Success in Cursor does not prove this step.

## Publish and keep using

Publish an item from Bettership Studio, then ask Grok Bot to use it. Publish a revision when you want a new version to become available. A task underway keeps its original version, and your next use loads the current one. You don't reinstall each item or revision.

If a required reference is unavailable, Grok Bot should stop and explain what is missing. Reconnect with Library access when the method needs a resource. The plugin does not create Bots, install scripts, or grant execution tools.

Disconnect Bettership in **Settings → Connectors & MCP** to stop future reads. Removing the plugin from Grok Bot may leave the connection authorized. Neither action removes text Grok Bot has already received.
